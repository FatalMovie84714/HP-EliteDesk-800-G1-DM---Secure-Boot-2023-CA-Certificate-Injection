This repository presents two methods to inject the Secure-Boot-2023-CA-Certificate into the HP EliteDesk 800 G1 DM hardware.

README1.md describes using 'PHASE_1_PREPARE.ps1' together with 'PHASE_2_FLASH.ps1'.

Alternatively, README2.md describes using 'HPElitedesk800G1.ps1'.

Both are intended to accomplish the same thing. 

README2.md describes how 'HPElitedesk800G1.ps1' is run twice.

README1.md describes how the same task is split between 'PHASE_1_PREPARE.ps1' and 'PHASE_2_FLASH.ps1'.
